# 像素军团 Pixel Legion

竖屏 1v1 翻牌像素对战小游戏。攒兵、成波冲锋，像素小兵一格一格翻过去冲向对方基地，先把对方基地打空的一方获胜。一局 3 分钟。

**在线试玩：** https://yukolo2009-lab.github.io/pixel-legion/

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 按住 → 上拨 | 蓄兵后成波发射，至少 3 个 |
| ↓ 下拨 | 升起盾墙，挡碎来兵（耗 2 兵） |
| ↓↑ 快划 V 字 | 弹反碰到的敌兵，落地变成台地（耗 1 兵） |
| 斜着拨 | 小兵沿对角线翻转前进 |

- 兵力是唯一的资源，发兵、盾墙、弹反都要花兵
- 两波兵相撞，按兵数相减，多的一方剩下的继续冲
- 一次发满 10 个兵，自动带一道浪涌
- 最后一分钟进入狂热阶段，节奏翻倍

模式：人机（简单 / 普通 / 困难）、同屏双人（手机平放，两人各拨半屏）。

左侧“调试”栏可以开关正在测试的效果。建议用手机竖屏打开。
