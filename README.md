# 像素军团 Pixel Legion

竖屏 1v1 翻板像素对战小游戏。整个棋盘是一面 3D 翻牌屏：兵营攒兵、成波冲锋，翻板一格一格滚向对方基地，先把对方基地打空的一方获胜。一局 3 分钟。

**在线试玩：** https://yukolo2009-lab.github.io/pixel-legion/

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 按住 → 左右瞄准 → 上拨 | 兵营里的兵被吸过来，从松手那一列成波发射（至少 3 个） |
| 往下拉住 | 立刻举起弧形盾墙，挡碎来兵，松手放下（耗 2 兵） |
| 拉住后往上一弹 | 橡皮筋弹反：兜住的敌兵被弹回去，落地变成台地（再耗 1 兵） |
| 斜着拨 | 整波沿对角线翻滚 |

- 兵力是唯一的资源，发兵、盾墙、弹反都要花兵
- 一波兵排成箭头阵冲锋，两波相撞按兵数相减，多的一方剩下的继续冲
- 一次发出大波兵会带一道浪涌，气浪压过的地面会起伏
- 最后一分钟进入狂热阶段，节奏翻倍

模式：人机（简单 / 普通 / 困难）、同屏双人（手机平放，两人各拨半屏）。

左侧常驻“调试”栏可以调数值、开关正在测试的效果（适合在电脑上测试，可点“收起”收窄）。需要联网加载 3D 引擎。
