# 像素军团 Pixel Legion

竖屏 1v1 翻牌像素对战小游戏。手指上拨，像素小兵一格一格翻过去冲向对方基地，先把对方基地打空的一方获胜。一局 3 分钟。

**在线试玩：** https://yukolo2009-lab.github.io/pixel-legion/

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| ↑ 上拨 | 从这一列发兵 |
| ↓ 下拨 | 升起盾墙，挡碎来兵 |
| ↓↑ 快划 V 字 | 弹反：来兵变成你的兵冲回去 |
| 拖动技能牌 | 拖到战场上松手释放 |

- 兵力随时间生成，技能牌消耗能量；自己的兵阵亡、基地挨打都会涨能量
- 小兵走过的格子染成你的颜色，在自己的领地上走得更快
- 打得越多，出兵口越宽，一拨能并排发出更多兵
- 最后一分钟进入狂热阶段，节奏翻倍

模式：人机（简单 / 普通 / 困难）、同屏双人（手机平放，两人各拨半屏）。

建议用手机竖屏打开。
