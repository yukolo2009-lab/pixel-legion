# 像素军团 Pixel Legion

竖屏 1v1 翻板像素对战小游戏。整个棋盘是一面 3D 翻牌屏：双方不断自动出兵，在中间顶成一条战线；往吃紧的地方派增援，把战线顶过去，冲垮对方基地。一局 3 分钟。

**在线试玩：** https://yukolo2009-lab.github.io/pixel-legion/

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 按住 → 左右瞄准 → 上拨 | 兵营里的兵被吸过来，从松手那一列派出增援（至少 3 个） |
| 往下拉住 | 立刻举起弧形盾墙，挡碎来兵，松手放下（耗 2 兵） |
| 拉住后往上一弹 | 橡皮筋弹反：兜住的敌兵翻成己方兵掉头冲回去（再耗 1 兵） |

- 自动兵不花钱；增援、盾墙、弹反都要花兵营里的兵
- 两边前排顶在一起比推力：身后人多的一方把战线往前推，前排逐个被磨掉
- 金色战线越亮越粗的地方越吃紧，撞击处会荡开一圈圈波纹
- 一次发出大波兵会带一道浪涌，气浪压过的地面会起伏
- 最后一分钟进入狂热阶段，节奏翻倍

模式：人机（简单 / 普通 / 困难）、同屏双人（手机平放，两人各拨半屏）。

左侧常驻“调试”栏可以调数值、开关正在测试的效果（适合在电脑上测试，可点“收起”收窄）。需要联网加载 3D 引擎。
